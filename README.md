# Multi-Document Chat App (CDV3400 CA-3)

Chat with many files at once. Upload your documents, click **Submit & Process**, and ask
questions. Answers are generated by Google Gemini from the most relevant parts of your files
and cite the file and the page / slide / rows they came from.

## Supported file types
PDF, Word (`.docx`, `.doc`), PowerPoint (`.pptx`, `.ppt`), CSV, JSON, YAML (`.yaml`, `.yml`), TXT.

## Architecture
```
Files -> format-specific reader -> text sections -> chunks (3000 chars, 300 overlap)
      -> Gemini embeddings -> FAISS vector index
Question -> embedding -> top 3 similar chunks -> Gemini LLM -> answer + sources
```

## Tech stack
Python 3.12, Streamlit, LangChain, Google Gemini (embeddings + chat), FAISS, pypdf,
python-docx, python-pptx, olefile, PyYAML, Docker, Google Cloud Run.

## Get a Gemini API key
Create a free key at https://aistudio.google.com/apikey

## Run locally
```bash
pip install -r requirements.txt
export GOOGLE_API_KEY=your_key_here        # Windows PowerShell: $env:GOOGLE_API_KEY="your_key_here"
streamlit run app.py
```
Try the files in `sample_files/` first.

Old `.doc` files need the `catdoc` tool (`sudo apt install catdoc` on Linux,
`brew install catdoc` on Mac). Without it, `.doc` files are skipped with a message;
all other formats work without it.

## Run with Docker
```bash
docker build -t multidoc-chat .
docker run -p 8080:8080 -e GOOGLE_API_KEY=your_key_here multidoc-chat
```
Open http://localhost:8080

## Deploy on Google Cloud Run
```bash
gcloud run deploy multidoc-chat --source . --region asia-south1 \
  --allow-unauthenticated --set-env-vars GOOGLE_API_KEY=your_key_here
```

## Notes
- Scanned PDFs and images have no text layer and cannot be read.
- Only the first 1,000 rows of each CSV are read (`MAX_TABLE_ROWS` in `app.py`).
- The index lives in memory for the session; refreshing the page clears it.
- The chat model can be changed with the `GEMINI_MODEL` environment variable.
